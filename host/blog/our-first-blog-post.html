The Genesis

This is the first blog post made using this mini blogging engine.

I've recently finished building my first ever blogging engine and now it's time to test it out. If this post has successfully loaded it means that the blogging engine is working.

What now?

Okay, we've created the foundation for making blogs, but now comes the real question: what are we even going to post here? Well, we're going to post here whatever we consider it's interesting enough to be worth making a blog post about. If we're working on a project, perhaps a game or a useful tool, it will probably be mentioned in one of the posts.
